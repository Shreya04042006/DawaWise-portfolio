# DawaWise + Data Science Portfolio

A responsive static portfolio starter built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page content
- `styles.css` — design and responsive layout
- `script.js` — mobile navigation and footer year

## Before publishing
Search the files for square-bracket placeholders and replace them:
- `[Your Name]`
- `[Your role]`, `[Add technologies]`, `[Prototype / Live]`
- `YOUR_EMAIL@example.com`
- `YOUR-LINKEDIN`
- `YOUR-GITHUB`

Also verify that each project description, technology, award and feature is accurate. Add links to project repositories or demos where available. Do not publish private data, API keys or credentials.

## Deploy with Vercel
1. Create a GitHub repository named `dawawise-portfolio`.
2. Upload these four files to the repository root.
3. In Vercel, choose **Add New → Project** (or **Import Project**).
4. Import the GitHub repository.
5. Framework preset: **Other**. Build command and output directory can be left blank for this static site.
6. Deploy.

## Connect your domain later
After the first successful deployment, open the project in Vercel → Settings → Domains and add `dawawise.xyz`. Follow the exact DNS instructions Vercel displays, then add those records in the DNS manager for your registrar. Do not change nameservers or delete existing DNS records unless the registrar/Vercel instructions specifically require it.
